# CodeAlpha Data Visualization Project

## Project Overview
This project uses data visualization techniques to present insights from a book dataset through clear charts and a dashboard.

## Objectives
- Visualize book price distributions.
- Compare book price categories.
- Display rating distributions.
- Explore the relationship between price and rating.
- Create a combined visualization dashboard.

## Tools and Technologies
- Python
- Pandas
- Matplotlib

## Files Included
- `data_visualization.py` — Visualization source code.
- `books_dataset_5_pages.csv` — Dataset used for visualization.
- `chart_1_price_distribution.png`
- `chart_2_price_categories.png`
- `chart_3_rating_distribution.png`
- `chart_4_price_vs_rating.png`
- `books_visualization_dashboard.png`
- Task 3 PDF report.

## How to Run
Install the required libraries:

`pip install pandas matplotlib`

Run the script:

`python data_visualization.py`

Ensure the CSV dataset is available at the path specified in the script.

Completed for educational purposes as part of the CodeAlpha Data Analysis Internship.
